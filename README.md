# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, and Power BI. The objective is to identify purchasing patterns, customer segments, product performance, and other business insights.

## Tools & Technologies

- Python
- Pandas
- PostgreSQL
- Power BI

## Project Workflow

1. Data cleaning and preprocessing using Python and Pandas
2. Data analysis using PostgreSQL and SQL
3. Data visualization and dashboard creation using Power BI
4. Analysis of customer purchasing behavior and business trends

## SQL Analysis

The analysis covers 10 business questions related to:

- Revenue by gender
- Customer spending
- Product ratings
- Shipping methods
- Subscription behavior
- Discount usage
- Customer loyalty
- Product performance
- Repeat purchases
- Revenue by age group

## Power BI Dashboard

The project includes an interactive Power BI dashboard for exploring customer behavior and key performance indicators.
